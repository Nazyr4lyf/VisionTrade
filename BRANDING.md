# VisionTrade Branding

The supplied VisionTrade logo has been integrated into the Android launcher icon resources.

- `branding/VisionTrade-logo.png` — master logo asset
- `app/src/main/res/mipmap-*` — launcher fallback icons
- `app/src/main/res/mipmap-anydpi-v26` — adaptive icon resources
- `app/src/main/res/drawable-xxxhdpi/ic_launcher_foreground.png` — adaptive foreground

The launcher icon intentionally uses the visual eye/chart mark rather than tiny text so it remains legible at Android launcher sizes.
